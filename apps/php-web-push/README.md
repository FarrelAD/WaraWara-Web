# PHP Web Push Implementation Guide

A native **Web Push Notification** backend implementation written in modern **PHP 8.3** using [`minishlink/web-push`](https://packagist.org/packages/minishlink/web-push), conforming to standard RFC 8291 / RFC 8292 VAPID encryption.

This implementation mirrors the architecture of the Node.js, Bun, FastAPI, and Golang applications in the repository.

---

## 📌 Architecture & Design

1. **Front Controller & Router (`public/router.php`)**:
   - Integrates with PHP's built-in web server (`php -S 0.0.0.0:8000`).
   - Serves static assets (`index.html`, `app.js`, `sw.js`, `style.css`) directly.
   - Dispatches REST endpoints (`/api/vapid-public-key`, `/api/subscribe`, `/api/send-notification`).
   - Handles CORS preflight headers (`OPTIONS`).

2. **Strongly Typed Models (`src/Models/`)**:
   - `PushSubscription` & `PushSubscriptionKeys`: Strongly typed PHP 8.3 readonly DTOs with `JsonSerializable` implementation.
   - `PushNotificationPayload` & `NotificationAction`: Payload data structures for push dispatch.

3. **Storage & Registry (`src/Services/SubscriptionService.php`)**:
   - Persists subscriptions into `storage/subscriptions.json` across HTTP requests with file locking (`LOCK_EX`).
   - Provides methods for registering, retrieving, and pruning expired subscriptions.

4. **WebPush Client (`src/Services/PushService.php`)**:
   - Encrypts payloads and signs VAPID headers using `Minishlink\WebPush\WebPush`.
   - Flushes push dispatches and inspects vendor responses.
   - Automatically detects expired subscriptions (`404 Not Found` or `410 Gone`) and prunes them from storage.

## 🚀 Getting Started

### Prerequisites
- **PHP**: `^8.2` or `^8.3` with `curl`, `openssl`, `mbstring`, and `bcmath` extensions enabled.
- **Composer**: `^2.x`

### 1. Install Dependencies
```bash
composer install
```

### 2. Configure VAPID Keys
The application automatically reads the root `.env` file generated by `pnpm generate-vapid`:
```env
VAPID_PUBLIC_KEY=your_public_key
VAPID_PRIVATE_KEY=your_private_key
VAPID_SUBJECT=mailto:admin@example.com
PORT=8000
```

### 3. Run the Development Server
```bash
composer start
```
Open `http://localhost:8000` in your web browser.

## 📡 API Reference

### 1. `GET /api/vapid-public-key`
Returns the VAPID public key needed by the browser's `PushManager`:
```json
{
  "publicKey": "BI..."
}
```

### 2. `POST /api/subscribe`
Registers a browser push subscription:
```json
{
  "endpoint": "https://fcm.googleapis.com/fcm/send/...",
  "expirationTime": null,
  "keys": {
    "p256dh": "...",
    "auth": "..."
  }
}
```
**Response (201 Created):**
```json
{
  "message": "Subscription stored successfully on PHP server",
  "id": "7b8a3e9c1d2f4a5b",
  "totalSubscriptions": 1
}
```

### 3. `POST /api/send-notification`
Dispatches a web push payload to all registered subscriptions:
```json
{
  "title": "Hello from PHP!",
  "body": "Web push notification sent via minishlink/web-push",
  "tag": "php-demo",
  "delaySeconds": 0
}
```
**Response (200 OK):**
```json
{
  "message": "Push notification process initiated on PHP!",
  "subscribersTargeted": 1,
  "results": {
    "sent": 1,
    "failed": 0,
    "details": [
      {
        "endpoint": "https://fcm.googleapis.com/fcm/send/...",
        "success": true
      }
    ]
  }
}
```
